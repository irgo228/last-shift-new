# Последняя смена MINI 1.1 — UI FIX

Обновление существующей MINI 1.0. База Supabase, RPC, таймеры, ответы, правильные ключи, изображения и игровая логика не изменены.

## Изменения

- Технологические схемы на экранах Host и Player используют доступную ширину, сохраняя пропорции и края. Общий `ZoomableDiagram` открывает прокручиваемый полноэкранный просмотр с кнопками изменения масштаба. Игровой таймер не приостанавливается.
- На титульном изображении QR-код и код комнаты находятся в верхней правой панели, а кнопка «Начать игру» — строго в нижней золотистой рамке. На небольшом экране Host те же функциональные элементы выводятся отдельно под уменьшенной титульной картинкой, поскольку поверх неё физически не помещаются.
- На `final.jpg` рейтинг привязан к десяти фиксированным строкам исходного изображения, поэтому единственный участник всегда оказывается на первой строке. Номера мест уже нарисованы: дублировать их в HTML не нужно. Имя победителя и его баллы располагаются в собственных рамочных областях. На мобильном Host предусмотрен читабельный список результатов под уменьшенной картинкой, а не поверх декоративной таблицы.
- Текст третьего вопроса теперь: «Каким должно быть давление в верхней части колонны по отношению к давлению в рефлюксной ёмкости?»
- Ключи Б / Г / В не изменены. Для вопроса 2 закрытый Z-005 намеренный; неверный вариант про него сохранён. Причина запрета запуска — закрытый Z-006.

## Как опубликовать на существующем сайте

1. **Не создавайте новый репозиторий.** Взять актуальный GitHub-репозиторий `last-shift-new`, на ветке текущей MINI 1.0 применить `git apply Последняя_смена_MINI_v1_1_UI_FIX.patch`. Если файлы в GitHub уже изменялись, сначала посмотреть diff, не перетирать их автоматически. В архиве также есть полный обновлённый исходный проект.
2. Установить зависимости и выполнить `npm ci` при существующем lock-файле либо `npm install`, затем `npm test`, `npm run check:assets` и `npm run build`. Если build не проходит, не публиковать.
3. Сделать commit `MINI 1.1 UI FIX` и push в ветку, к которой подключён Tatnet. Проверить, что Tatnet поднял новую ревизию. **Не менять секреты и SQL.**
4. Проверить опубликованный адрес https://last-shift-new.tatnet.app на телефоне и компьютере. Сделать настоящие скриншоты с разрешениями из задания и проверить рамки.
5. Пройти новую тестовую комнату целиком: 30 секунд на каждый вопрос, 10 секунд на показ ответа, рейтинг для 1, 3, 10 и, при возможности, 15 игроков. Особое внимание — нет ли обрезки схемы на телефоне при увеличении и попадает ли первый игрок строго в первую строку.

Сборка V1.1 — **исходники для обновления, не объявленная production-ready версия**.
